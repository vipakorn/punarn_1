# ปันอ่าน (PunArn)

ต้นแบบระบบห้องสมุด version 1 (Library System Mockup v1)

## วัตถุประสงค์

PunArn คือแพลตฟอร์มบริการห้องสมุดโรงเรียนแบบใช้ทรัพยากรร่วมกันบนคลาวด์ (cloud-based shared service) สำหรับโรงเรียนมัธยมศึกษาไทย โปรเจกต์นี้ใช้ออกแบบและทดสอบ UX/UI ก่อนพัฒนาระบบจริง สำหรับนักเรียน ครูบรรณารักษ์ และผู้บริหาร

PunArn is a cloud-based shared library service for Thai secondary schools. This repository holds the UX/UI plan and a clickable prototype.

## สถานะปัจจุบัน

อยู่ในช่วงวางแผน UI (UI planning stage)

- แผนการออกแบบ UX/UI เสร็จแล้ว
- ต้นแบบคลิกได้ (clickable prototype) เสร็จแล้ว ใช้ข้อมูลจำลอง
- ยังไม่มีระบบหลังบ้านและฐานข้อมูลจริง

## โครงสร้างโฟลเดอร์

| โฟลเดอร์ | เนื้อหา |
|---|---|
| `prototype/punarn_prototype.html` | ต้นแบบไฟล์เดียว เปิดในเบราว์เซอร์ได้ทันที |
| `prototype/src/` | ซอร์สของต้นแบบ (CSS, JS, ข้อมูลหนังสือ) และ `build.py` |
| `data/` | ข้อมูลหนังสือตัวอย่าง 200 เล่ม (CSV) และสคริปต์สร้างไฟล์ |
| `docs/` | เอกสารข้อกำหนดความต้องการ (SRS) ฉบับร่างที่แปลงเป็น Markdown |

## วิธีเปิดต้นแบบ

เปิดไฟล์ `prototype/punarn_prototype.html` ในเบราว์เซอร์ ไม่ต้องติดตั้งอะไรเพิ่ม

บัญชีทดลอง: นักเรียนรหัส `41208` รหัสผ่าน `1234` / ครู PIN `1234`

## สร้างต้นแบบใหม่จากซอร์ส

```
python3 prototype/src/build.py
```

## ข้อจำกัดของต้นแบบ

- ภาพปกหนังสือโหลดจากเว็บภายนอก (hotlink) ต้องต่อเครื่องกับอินเทอร์เน็ต
- กล้องสแกนและการนำเข้าไฟล์เป็นการจำลอง
- ข้อมูลเก็บในหน่วยความจำ รีเฟรชหน้าแล้วข้อมูลกลับเป็นค่าเริ่มต้น
